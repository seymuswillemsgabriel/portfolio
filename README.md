# Portfolio · Gabriel Seymus

Mi web de portfolio personal: quién soy, con qué tecnologías trabajo, mis proyectos y cómo contactarme.

🌐 **[Abrir el portfolio →](https://seymuswillemsgabriel.github.io/portfolio/)**

## Cómo está hecho

- **HTML** para la estructura de la página (`index.html`)
- **CSS** para el diseño, adaptado a móvil y con modo oscuro (`style.css`)
- **JavaScript** para marcar en el menú la sección que estás viendo y poner el año en el pie (`script.js`)

Está publicado con **GitHub Pages** desde la rama `main`.
